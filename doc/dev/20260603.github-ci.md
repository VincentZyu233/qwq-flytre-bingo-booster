# GitHub CI 计划

## 目标

复用旧插件 `qwq-spigot-plugin` 的 CI 模式：
- commit 含 `build action` → 自动构建，上传 artifact
- commit 含 `build release` → 自动构建 + 创建 GitHub Release

## 需要做的事

1. **生成 Gradle Wrapper**
   - 当前项目缺 `gradlew` / `gradlew.bat` / `gradle-wrapper.jar`
   - 本地跑 `gradle wrapper --gradle-version 8.8` 生成后提交

2. **创建 `.github/workflows/build.yml`**
   - 从旧插件 `build.yml` 复制，改 3 处：
     - `build.gradle` → `build.gradle.kts`（version 解析行）
     - artifact 名: `qwq-spigot-plugin` → `qwq-flytre-bingo-booster`
     - release 上传文件名匹配

3. **Commit Message 规则**
   - commit message 包含 `build action` → 只构建
   - commit message 包含 `build release` → 构建 + 发布 Release
   - PR 到 main → 只构建不发布

4. **验证**
   - push 到 main，看 Actions 页是否触发 build
