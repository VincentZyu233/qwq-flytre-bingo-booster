## 🚀 How to Use

### 🗺️ Install the Map (vanilla, untouched)

1. Download `bingo_1_21_5.zip`
2. Extract into your server's `world/` directory
3. Ensure `server.properties` has `level-name=world`

### 🧩 Install the Plugin (for the enhanced experience!)

1. Download the latest `qwq-flytre-bingo-booster.jar` from [releases](https://github.com/VincentZyuApps/qwq-flytre-bingo-booster/releases)
2. Place it in your server's `plugins/` directory
3. Restart the server 🎉

> 💡 **How it works**: The map uses Minecraft's native Team system to assign teams.
> The plugin reads those teams → dyes chat names → shows sidebar → applies effects.
> **Zero modifications to the map itself!** ✅
