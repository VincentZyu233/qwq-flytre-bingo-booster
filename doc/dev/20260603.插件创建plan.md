# qwq-flytre-bingo-booster 迁移计划

## 目标

从 `qwq-spigot-plugin` (Java) 中提取 Bingo 相关功能到独立插件 `qwq-flytre-bingo-booster` (Kotlin)。

## 涉及的原版功能模块

| 模块 | 原 Java 类 | 作用 |
|------|-----------|------|
| TeamColor | `qwqTeamColorCommand` + `qwqScheduledTeamColorTask` | 根据计分板值(1-4)给玩家名染色（红/黄/绿/蓝），每 tick 运行一次 |
| BingoSidebar | `qwqBingoSidebarCommand` | 在侧边栏显示队伍及成员列表，每 10 秒更新一次 |

## 新项目文件结构

```
src/main/kotlin/qwq/zyu/qwqFlytreBingoBooster/
├── QwqFlytreBingoBooster.kt          ← 主类
├── teamcolor/
│   ├── TeamColorCommand.kt           ← /qwq_set_scheduled_team_color_dye 命令
│   └── TeamColorTask.kt              ← 定时染色任务
└── bingosidebar/
    └── BingoSidebarCommand.kt        ← /qwq_bingo_sidebar 命令
```

## 迁移步骤

### Step 1: 更新 plugin.yml
- 添加 `load: POSTWORLD`
- 添加两个命令定义（沿用旧命令名）

### Step 2: 迁移 TeamColor 模块
- `TeamColorTask` — 读取主计分板 `teamDisplay` objective，根据玩家分数(1-4)设置 displayName 和 playerListName
- `TeamColorCommand` — true/false 开关染色
- **注意点**：原 Java 代码中 `cancel()` + 再次 `runTaskTimer` 会导致调度器异常（已取消的 BukkitRunnable 不可复用在旧版也有此 bug），新版已在 `onEnable` 中长期运行 Task，命令只切换 `isEnabled` flag，规避了此问题。

### Step 3: 迁移 BingoSidebar 模块
- `BingoSidebarCommand` — 创建独立 sidebar scoreboard，按队伍分组显示在线玩家

### Step 4: 更新主类
- 注册两个命令的 executor

## 与原版的差异/改进

| 项目 | 原版 | 新版 |
|------|------|------|
| 语言 | Java 21 | Kotlin 2.1.10 |
| 构建 | Gradle (Groovy) | Gradle Kotlin DSL + Shadow |
| Task 生命周期 | 命令控制 start/stop | `onEnable` 启动，命令只切 flag |
| 代码 | 混用的命名/typo | Kotlin 惯用风格 |
| 打包 | 无 shade | Shadow shade kotlin-stdlib |
